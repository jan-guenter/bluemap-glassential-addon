# Compatibility contract

Supported only as an implementation target for this exact tuple:

- All the Mons 1.2.0, pack commit
  `c7bb230f21d14d26859d0b92548f089b3a493ad9`;
- Minecraft 1.21.1, NeoForge 21.1.248, Java 21;
- BlueMap feature-backport commit
  `7e07f4e74ec1e92a6ead9aa1e66054af3e133aac`, API commit
  `285c9a60eff3ac2b0cab308ce1058d1565be0971`;
- Adapter API source gitlink `e81f08bc4bfbf02d810ec8949a019130e2e61634`,
  source tree `2f974c9bb2ba13888d69682f86f30f58922d30eb`;
- Fusion resource-model source gitlink
  `3ddd5d39bb7cc8664c242aedd849a636316075c2`, source tree
  `6e85031ff2f0e7417a7a2fb0babbf7ed5a4f218a`;
- Glassential Renewed 3.4.5, 702,249 bytes, SHA-256
  `1f0c8f7533bf3b2002575219ba795fd32a44cc5085c2710624ebbf69e6121471`;
- Fusion 1.3.12, 923,270 bytes, SHA-256
  `17f5215648a98bcde4134577b013200dbf363273ae282449c51408ae8346f2fa`.

This is an evidence lock, not a range claim or a statement that runtime
validation has passed. Any pack, mod, Minecraft, loader, or BlueMap change
requires a fresh artifact/resource census, regenerated profile, tests, staging
render, exact-client comparison, rollback proof, version change, and review.

Dimension-preserving PNG pixel overrides are supported. Structural model,
blockstate, metadata, and host-ABI overrides deactivate the route. No arbitrary
resource pack, Glassential fork, Fusion version, vanilla ID, or other namespace
is claimed.
