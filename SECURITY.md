# Security policy

This technically staged and owner-accepted alpha candidate has no supported
production version. The 2026-08-16 acceptance authorizes only immutable
`0.1.0-alpha.1` prerelease publication; neither it nor the disposable-host pass
authorizes production deployment or creates a production-support commitment.
Report suspected resource-parser denial of service, namespace collision,
archive traversal, activation bypass, NBT parsing, mimic recursion, unsafe
fallback, or publication-boundary defects privately to the repository owner
before public disclosure.

The interpreter is intentionally bounded to exact artifacts, a fixed 204-path
operator closure, a separate 22-path host ABI, exact state/NBT schemas, exact
namespaces, and a fixed predicate/layout vocabulary. Unknown or malformed input
must deactivate the route, atomically use stock rendering, or follow an
explicitly tested client normalization such as invalid one-way `Mimic` to
`minecraft:iron_block`; it must never become a broader interpreter.

Do not attach third-party JARs/assets, production maps, server logs,
credentials, world data, player data, or resource-pack assets to reports.
