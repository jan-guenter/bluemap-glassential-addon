# Contributing

Keep contributions inside the exact profile and licensing boundary documented
in README and `AGENTS.md`. Do not copy or adapt Glassential or Fusion code or
assets. Operator-installed resources may be parsed only through the bounded
metadata and static-render contract.

Changes to the artifact tuple, 49-ID allowlist, legal-state schemas, resource
closure, predicates, layouts, NBT decoding, BlueMap ABI, or publication
identity require regenerated evidence, tests, documentation, and a version
increase through a pull request. Pixel-only resource-pack overrides must remain
supported.

Use LF endings, preserve SPDX/attribution headers, update deterministic outputs
through their generators, and run the focused local gate from README. Do not
commit build output or third-party inputs. Do not represent an unobserved
staging, client, rollback, or release result as passed.
